# Personal Expense Tracker

A simple expense tracker using Python Flask.

## Features

- Add expenses
- View expenses
- Delete expenses
- Calculate total expenses

## Technologies

- Python
- Flask
- HTML
- CSS
- Git and GitHub

## Installation

Clone the repository:

git clone YOUR_REPOSITORY_URL

Install dependencies:

pip install -r requirements.txt

Run application:

python app.py

Open http://127.0.0.1:5000/
